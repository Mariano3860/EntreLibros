# AGENTS de scripts

Estas reglas complementan las del `AGENTS.md` raíz y aplican a `scripts/`.

- Cada script debe explicar propósito, entradas, salidas, permisos y limitaciones en `scripts/README.md`.
- No imprimas secretos ni sobrescribas secciones manuales sin una opción explícita.
- Comprueba que dependencias y comandos documentados existan realmente en `package.json`.
- Si un script actualiza documentación o backlog, conserva el formato existente y valida el diff antes de ejecutarlo sobre datos reales.
